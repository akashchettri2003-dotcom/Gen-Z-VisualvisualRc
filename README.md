# GEN/VISUAL PRO

A production-minded starter platform for publishing and reading independent novels and comics.

## Run on Replit
1. Upload/extract this ZIP into a new Replit project.
2. Open the Shell.
3. Run `npm install`.
4. Run `npm start`.
5. Replit will expose the web app.

## Included
- Responsive editorial homepage matching the supplied Gen/Visual aesthetic
- Novel and comic discovery
- Search, filters, favorites and reading progress
- Reader with chapters/pages and keyboard controls
- Account registration/login with hashed passwords
- Creator dashboard with publishing workflow
- SQLite persistence
- Helmet security headers, compression and basic API rate limiting
- Admin-ready role model
- API-driven architecture

## Important for production
Payments, email verification, object storage, CDN, DRM and social login require real provider credentials and infrastructure. This starter intentionally does not fake real transactions.
